# Gasca Plumbing & Rooter

## Run locally

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

## Build and deploy

Create a production build with:

```sh
npm run build
```

Deploy the contents of `dist/` to any static web host. The build uses relative asset paths, so it can be hosted at a domain root or under a subpath. Configure the host to serve `index.html` for page routes.

Photos and fonts are bundled with the site and included in `dist/`; serving the website does not require external image or font services.
